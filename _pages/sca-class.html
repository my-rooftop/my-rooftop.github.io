디바이스에서 새어 나오는 전력 소모로부터 비밀 정보를 알아내는 하드웨어 해킹 기법, '부채널 분석'을 하루 만에 직접 체험해 보세요!

10월 23일(금) 13:00 – 18:30 E3 223호 5명 선정 🍕 간식 무한 제공
신청하기 어떤 수업인가요?
달구가 칩에 프로브를 갖다 댑니다…

전력 소모 파형 수집 → 통계 분석 → 비밀키 복구. 이 과정을 실제 장비로 직접 해봅니다.

부채널 분석이란?

암호 알고리즘은 수학적으로는 안전해도, 그걸 실행하는 칩은 전력을 소모하고 전자파를 내보냅니다. 이 "새어 나오는" 신호를 측정해 통계적으로 분석하면, 칩 안에 숨겨진 비밀키를 알아낼 수 있습니다. 이것이 부채널 분석입니다.

이번 클래스에서는 암호 알고리즘을 배우고, 실제 장비로 AES 비밀키를 복구하는 실험까지 직접 해봅니다. 스마트카드, 자동차 키, IoT 기기 보안 인증에 실제로 쓰이는 기술입니다.

진로를 탐색 중인 학생, 하드웨어 해킹에 관심 있는 학생 모두 환영합니다. 단, Python과 C 기본 문법은 필수입니다. 실험 코드를 직접 다루기 때문입니다.
