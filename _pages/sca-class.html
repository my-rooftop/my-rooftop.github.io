달구가 칩에 프로브를 갖다 댑니다…

전력 소모 파형 수집 → 통계 분석 → 비밀키 복구. 이 과정을 실제 장비로 직접 해봅니다.Collect power traces → statistical analysis → key recovery. You will do this yourself on real hardware.

부채널 분석이란?What is side-channel analysis?

암호 알고리즘은 수학적으로는 안전해도, 그걸 실행하는 칩은 전력을 소모하고 전자파를 내보냅니다. 이 "새어 나오는" 신호를 측정해 통계적으로 분석하면, 칩 안에 숨겨진 비밀키를 알아낼 수 있습니다. 이것이 부채널 분석입니다.A cipher can be mathematically secure, yet the chip running it consumes power and emits electromagnetic signals. Measure these "leaking" signals, analyze them statistically, and the secret key hidden inside the chip can be recovered. That is side-channel analysis.

이번 클래스에서는 암호 알고리즘을 배우고, 실제 장비로 AES 비밀키를 복구하는 실험까지 직접 해봅니다. 스마트카드, 자동차 키, IoT 기기 보안 인증에 실제로 쓰이는 기술입니다.In this class you will learn the cipher and then recover an AES secret key on real equipment. The same technique is used in security certification of smart cards, car keys, and IoT devices.

진로를 탐색 중인 학생, 하드웨어 해킹에 관심 있는 학생 모두 환영합니다. 단, Python과 C 기본 문법은 필수입니다. 실험 코드를 직접 다루기 때문입니다.Students exploring their career path and anyone curious about hardware hacking are welcome. Basic Python and C are required, because you will work with the experiment code yourself.
